# TripFlow v0.2 Functional

Interactive travel planner built with React + TypeScript + Vite.

## Working features
- Create/delete/favorite/search/filter trips
- Open every trip
- Multi-day itinerary with add/edit/delete and drag reorder
- Dynamic budget with add/edit/delete expenses
- Dynamic packing checklist with add/delete/check progress
- Trip notes
- LocalStorage persistence
- Combined sidebar views
- Responsive UI

## Run on Windows PowerShell
```powershell
npm.cmd install
npm.cmd run dev
```
